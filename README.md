## 📖 使用说明

### 1. 计划编制
1. 切换到"三月滚动计划编制"
2. 上传托盘明细.xlsx
3. 上传先后行计划.xlsx
4. 点击"生成计划"

### 2. 数据管理

#### 托盘明细更新
1. 切换到"数据管理" -> "托盘明细更新"
2. 点击上传文件（支持多选）
3. 系统自动增量更新并去重
4. 实时显示处理进度

#### 数据查询
1. 切换到"数据管理" -> "数据查询"
2. 输入查询条件（船号/分段号/托盘号/来源）
3. 点击"查询"
4. 查看结果（包含名称列）
5. 可导出查询结果

### 3. 看板功能
- **单船看板**: 选择船号查看详情
- **月度看板**: 查看月度统计图表
- **双周看板**: 查看双周进度

### 4. 数据备份
- 点击右上角"💾 备份"导出JSON
- 通过"📥 恢复"导入备份

## 🔧 故障排查

### 问题1: 页面空白或报错
**原因**: JS库文件未正确加载

**解决**:
1. 检查3个文件是否在同一目录
2. 检查 `xlsx.full.min.js` (约720KB) 和 `chart.min.js` (约220KB) 是否存在
3. 如果文件太小（几十字节），重新下载
4. 按F12打开控制台查看错误

### 问题2: 无法导入Excel
**原因**: xlsx库未加载

**解决**:
1. 确认 `xlsx.full.min.js` 文件正确
2. 检查文件大小约720KB
3. 清除浏览器缓存后重试

### 问题3: 图表不显示
**原因**: Chart.js库未加载

**解决**:
1. 确认 `chart.min.js` 文件正确
2. 检查文件大小约220KB
3. 重新下载chart.min.js

### 问题4: 大文件导入卡顿
**正常现象**: 系统自动分批处理

**建议**:
- 耐心等待进度条完成
- 低端电脑建议分批上传
