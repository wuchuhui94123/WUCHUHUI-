# 抖音自动化脚本

一个基于Python和ADB的抖音自动化脚本,可以自动刷视频、看直播、点赞、评论和关注,帮助你在抖音上轻松赚取生活费用。

## 功能特点

- ✅ 自动刷视频(可配置观看时长和数量)
- ✅ 自动看直播(可配置观看时长和互动频率)
- ✅ 智能点赞(随机概率,模拟真实用户)
- ✅ 自动关注(随机概率)
- ✅ 自动评论(可自定义评论内容)
- ✅ 详细的运行统计
- ✅ 模拟真实用户行为(随机延迟、随机位置点击)

## 系统要求

### Windows 11 系统
- Python 3.7 或更高版本
- Android模拟器(推荐使用以下之一):
  - 雷电模拟器 (LDPlayer)
  - 夜神模拟器 (Nox)
  - MuMu模拟器
  - BlueStacks

### 其他需求
- ADB (Android Debug Bridge) 工具
- 抖音APP (安装在模拟器中)

## 安装步骤

### 1. 安装Python

从 [Python官网](https://www.python.org/downloads/) 下载并安装Python 3.7+

确保在安装时勾选 "Add Python to PATH"

### 2. 安装Android模拟器

以雷电模拟器为例:

1. 下载并安装 [雷电模拟器](https://www.ldplayer.net/)
2. 启动模拟器,完成初始化
3. 在模拟器中安装抖音APP
4. 登录你的抖音账号

### 3. 配置ADB

#### 方法一: 使用模拟器自带的ADB

大多数模拟器都自带ADB工具,通常在安装目录下。

**雷电模拟器示例:**
```
C:\LDPlayer\LDPlayer9\adb.exe
```

记下这个路径,后面配置文件中会用到。

#### 方法二: 下载独立的ADB工具

1. 下载 [Android Platform Tools](https://developer.android.com/studio/releases/platform-tools)
2. 解压到一个目录,例如 `C:\adb`
3. 将该目录添加到系统环境变量PATH中

### 4. 启用模拟器的ADB调试

**雷电模拟器:**
1. 打开模拟器设置
2. 找到 "关于平板电脑" 或 "关于手机"
3. 连续点击 "版本号" 7次,开启开发者模式
4. 返回设置,进入 "开发者选项"
5. 开启 "USB调试"

**连接模拟器:**

打开CMD或PowerShell,输入:
```bash
adb connect 127.0.0.1:5555
```

不同模拟器的端口可能不同:
- 雷电模拟器: 5555, 5556, 5557 (多开时递增)
- 夜神模拟器: 62001
- MuMu模拟器: 7555

查看已连接设备:
```bash
adb devices
```

应该能看到类似输出:
```
List of devices attached
127.0.0.1:5555  device
```

### 5. 下载脚本

将以下文件放到同一个文件夹中:
- `douyin_bot.py` - 主程序
- `adb_controller.py` - ADB控制模块
- `config.json` - 配置文件

### 6. 配置脚本

编辑 `config.json` 文件,根据你的需求调整参数:

```json
{
  "adb_path": "adb",  // ADB路径,如果已添加到PATH则写"adb",否则写完整路径
  "device_name": "127.0.0.1:5555",  // 模拟器地址

  "video_settings": {
    "watch_duration_min": 15,  // 每个视频最短观看时长(秒)
    "watch_duration_max": 45,  // 每个视频最长观看时长(秒)
    "swipe_count": 50,  // 刷视频的数量
    "like_probability": 0.3,  // 点赞概率 (0-1)
    "comment_probability": 0.1,  // 评论概率 (0-1)
    "follow_probability": 0.05  // 关注概率 (0-1)
  },

  "live_settings": {
    "watch_duration_min": 180,  // 每个直播最短观看时长(秒)
    "watch_duration_max": 600,  // 每个直播最长观看时长(秒)
    "like_interval_min": 30,  // 点赞最短间隔(秒)
    "like_interval_max": 90,  // 点赞最长间隔(秒)
    "max_live_count": 5  // 观看直播的数量
  },

  "screen_resolution": {
    "width": 1080,  // 模拟器屏幕宽度
    "height": 2340  // 模拟器屏幕高度
  }
}
```

**重要配置说明:**

1. **adb_path**:
   - 如果ADB已添加到系统PATH,保持 `"adb"`
   - 否则填写完整路径,如 `"C:/LDPlayer/LDPlayer9/adb.exe"`

2. **device_name**:
   - 根据你的模拟器端口修改
   - 多开模拟器时,每个实例端口不同

3. **screen_resolution**:
   - 必须与模拟器分辨率一致
   - 可通过 `adb shell wm size` 查看

## 使用方法

### 基本使用

1. 启动Android模拟器
2. 确保抖音已登录
3. 打开CMD或PowerShell,进入脚本目录
4. 运行脚本:

```bash
# Windows
python douyin_bot.py

# 或者直接指定模式
python douyin_bot.py video   # 只刷视频
python douyin_bot.py live    # 只看直播
python douyin_bot.py both    # 两者都做
```

### 运行模式

程序支持三种运行模式:

1. **video** - 只刷视频
   - 自动滑动浏览视频
   - 随机点赞、关注
   - 统计观看数量

2. **live** - 只看直播
   - 进入直播间
   - 定期点赞互动
   - 自动切换直播间

3. **both** - 两者结合
   - 先刷视频,再看直播
   - 最大化赚取时长

### 停止脚本

按 `Ctrl + C` 可以随时停止脚本,程序会显示运行统计。

## 高级配置

### 调整点击位置

如果脚本点击位置不准确,可以修改 `douyin_bot.py` 中的坐标:

```python
# 点赞按钮位置
x = int(self.screen_width * 0.92)  # 调整这个比例
y = int(self.screen_height * 0.72)  # 调整这个比例
```

### 添加自定义评论

编辑 `config.json` 中的 `comments` 数组:

```json
"comments": [
  "主播好棒！",
  "666",
  "学到了",
  // 添加你自己的评论...
]
```

### 多开模拟器

1. 启动多个模拟器实例
2. 查看每个实例的端口: `adb devices`
3. 为每个实例创建独立的配置文件
4. 分别运行脚本

例如:
```bash
# 终端1
python douyin_bot.py video

# 终端2 (修改config.json中的device_name)
python douyin_bot.py live
```

## 注意事项

### 安全建议

1. **不要过度使用** - 建议每天运行时间不超过4-6小时
2. **调整参数** - 使点赞、关注概率接近真实用户
3. **定期休息** - 设置合理的观看时长和间隔
4. **多账号轮换** - 避免单个账号长时间运行

### 常见问题

**Q: 连接模拟器失败?**
- 检查ADB路径是否正确
- 确认模拟器已开启USB调试
- 尝试重启ADB: `adb kill-server && adb start-server`

**Q: 点击位置不准确?**
- 检查配置文件中的屏幕分辨率是否正确
- 调整代码中的点击坐标比例

**Q: 抖音检测到自动化行为?**
- 降低操作频率
- 增加随机性(修改延迟时间)
- 减少每日运行时长

**Q: 评论功能不工作?**
- 中文输入较复杂,需要额外配置输入法
- 默认评论功能已禁用,需要手动调整

**Q: 脚本运行中途崩溃?**
- 检查模拟器是否稳定
- 查看是否有弹窗干扰
- 增加异常处理的延迟时间
