# 新手安装指南

本指南将一步一步教你如何在Windows 11上安装和使用抖音自动化脚本。

## 第一步: 安装Python

### 1.1 下载Python

1. 访问Python官网: https://www.python.org/downloads/
2. 点击下载最新版本(推荐Python 3.11或3.12)
3. 下载完成后,双击安装包

### 1.2 安装Python

**重要**: 安装时请务必勾选 "Add Python to PATH"

![Python安装](https://docs.python.org/zh-cn/3/_images/win_installer.png)

1. 勾选 "Add Python to PATH"
2. 点击 "Install Now"
3. 等待安装完成
4. 点击 "Close"

### 1.3 验证安装

按 `Win + R`,输入 `cmd`,回车打开命令提示符

输入以下命令:
```bash
python --version
```

如果显示版本号(如 `Python 3.11.0`),说明安装成功。

## 第二步: 安装Android模拟器

我们推荐使用雷电模拟器,其他模拟器也可以。

### 2.1 下载雷电模拟器

访问官网: https://www.ldplayer.net/

点击"立即下载",下载完成后安装。

### 2.2 安装抖音APP

1. 打开雷电模拟器
2. 在模拟器中打开应用商店(内置的)
3. 搜索"抖音"
4. 点击安装
5. 安装完成后登录你的抖音账号

### 2.3 调整模拟器设置

**推荐设置:**
- 分辨率: 1080x2340 (手机竖屏)
- 内存: 4GB
- CPU核心数: 4核

在模拟器设置中可以调整这些参数。

## 第三步: 配置ADB调试

### 3.1 开启开发者模式

在模拟器中:
1. 打开"设置"
2. 找到"关于平板电脑"或"关于手机"
3. 找到"版本号"
4. **连续点击7次**
5. 会提示"您已处于开发者模式"

### 3.2 开启USB调试

1. 返回设置主页
2. 找到"开发者选项"(可能在"系统"或"更多设置"中)
3. 找到"USB调试",开启它
4. 弹出提示时点击"确定"

### 3.3 获取ADB路径

雷电模拟器自带ADB工具,通常在安装目录:

```
C:\LDPlayer\LDPlayer9\adb.exe
```

或

```
C:\LDPlayer\LDPlayer4\adb.exe
```

记下这个路径,一会要用。

### 3.4 测试ADB连接

打开命令提示符(cmd),输入:

```bash
# 如果ADB在系统PATH中
adb devices

# 或使用完整路径
C:\LDPlayer\LDPlayer9\adb.exe devices
```

如果显示:
```
List of devices attached
127.0.0.1:5555  device
```

说明连接成功!

如果没有显示设备,尝试先连接:
```bash
adb connect 127.0.0.1:5555
```

## 第四步: 下载脚本

### 4.1 创建文件夹

在你的电脑上创建一个文件夹,例如:
```
C:\Users\你的用户名\Desktop\抖音自动化
```

### 4.2 复制文件

将以下文件复制到这个文件夹:
- `douyin_bot.py`
- `adb_controller.py`
- `config.json`
- `启动脚本.bat`
- `README.md`

## 第五步: 配置脚本

### 5.1 打开配置文件

用记事本打开 `config.json`

### 5.2 修改ADB路径

找到这一行:
```json
"adb_path": "adb",
```

**情况1**: 如果ADB已在系统PATH中,保持不变

**情况2**: 如果需要指定路径,修改为:
```json
"adb_path": "C:/LDPlayer/LDPlayer9/adb.exe",
```

注意: 使用 `/` 而不是 `\`

### 5.3 修改设备地址

找到这一行:
```json
"device_name": "127.0.0.1:5555",
```

根据你的模拟器端口修改:
- 雷电模拟器: 通常是 5555
- 夜神模拟器: 通常是 62001
- MuMu模拟器: 通常是 7555

### 5.4 调整其他参数(可选)

```json
"video_settings": {
  "watch_duration_min": 15,     // 每个视频最短看15秒
  "watch_duration_max": 45,     // 每个视频最长看45秒
  "swipe_count": 50,            // 刷50个视频
  "like_probability": 0.3,      // 30%的概率点赞
  "follow_probability": 0.05    // 5%的概率关注
}
```

根据你的需要调整这些数字。

### 5.5 保存配置

保存并关闭 `config.json`

## 第六步: 运行脚本

### 方法一: 使用启动脚本(推荐)

双击 `启动脚本.bat`,按提示操作即可。

### 方法二: 命令行运行

1. 按住 `Shift`,在文件夹空白处右键
2. 选择"在此处打开PowerShell窗口"
3. 输入命令:

```bash
# 刷视频
python douyin_bot.py video

# 看直播
python douyin_bot.py live

# 两者都做
python douyin_bot.py both
```

### 6.1 首次运行

首次运行建议:
1. 选择"刷视频"模式
2. 设置较短的运行时间(如10个视频)
3. 观察脚本是否正常工作
4. 如果点击位置不准,需要调整坐标

### 6.2 停止脚本

按 `Ctrl + C` 可以随时停止。

程序会显示统计信息:
```
==================================================
运行统计:
  运行时长: 0小时 25分钟 30秒
  观看视频: 50 个
  点赞次数: 15 次
  关注次数: 2 次
==================================================
```

## 常见问题排查

### 问题1: 提示"找不到Python"

**原因**: Python没有添加到系统PATH

**解决方案**:
1. 重新安装Python,记得勾选"Add Python to PATH"
2. 或手动添加Python到PATH

### 问题2: ADB连接失败

**原因**: 模拟器未开启USB调试,或端口不对

**解决方案**:
1. 确认模拟器已开启USB调试
2. 在命令行执行: `adb connect 127.0.0.1:5555`
3. 尝试其他端口: 5556, 62001, 7555
4. 重启模拟器和ADB: `adb kill-server && adb start-server`

### 问题3: 点击位置不准确

**原因**: 屏幕分辨率配置不对

**解决方案**:
1. 在命令行执行: `adb shell wm size`
2. 查看输出,如: `Physical size: 1080x2340`
3. 修改config.json中的 `screen_resolution` 为对应值

### 问题4: 脚本运行但没有操作

**原因**: 可能抖音界面不在前台,或有弹窗

**解决方案**:
1. 确保模拟器中抖音在前台运行
2. 关闭所有弹窗
3. 手动进入抖音首页视频流
4. 再运行脚本

### 问题5: 账号被限制

**原因**: 操作频率过高,被检测为异常

**解决方案**:
1. 降低操作频率(减少点赞概率)
2. 增加观看时长
3. 减少每日运行时间
4. 更换账号

## 进阶使用

### 多开运行

如果你有多个抖音账号:

1. 打开多个模拟器实例
2. 每个实例分别配置
3. 查看每个实例的端口: `adb devices`
4. 为每个实例创建独立的config文件
5. 分别运行脚本

### 定时运行

使用Windows任务计划程序:

1. 打开"任务计划程序"
2. 创建基本任务
3. 设置触发器(如每天8点)
4. 操作选择"启动程序"
5. 程序填写: `python.exe`
6. 参数填写: `douyin_bot.py video`
7. 起始于: 脚本所在文件夹路径

### 日志记录

在脚本中添加日志功能,记录每次运行的详细信息,方便分析和优化。

## 安全提示

1. **不要泄露账号**: 不要在公共场合分享你的抖音账号
2. **适度使用**: 每天运行时间不要超过6小时
3. **多账号分散**: 不要在单个账号上过度使用
4. **定期检查**: 定期查看账号状态,避免被封
5. **遵守规则**: 不要用于违规行为
